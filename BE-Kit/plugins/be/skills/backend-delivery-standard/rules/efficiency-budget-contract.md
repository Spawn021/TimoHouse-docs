# Efficiency & Token Budget Contract

- Chỉ đọc file thật sự cần cho mode hiện tại; dùng Input ledger trong `workflow-status.md` làm danh sách đọc chính.
- Không chép nguyên SRS, API spec hay rule dài vào artifact; chỉ ghi section, endpoint, path hoặc rule liên quan.
- `BE plan` chỉ ghi quyết định riêng của task; plan ngắn, đủ để code.
- `BE cook` ưu tiên đọc task, plan, checklist, workflow-status, file code liên quan; không đọc lại report dài không liên quan.
- `BE review` chỉ report issue có evidence.
- Context quá lớn thì dừng và đề xuất chia task theo module.
