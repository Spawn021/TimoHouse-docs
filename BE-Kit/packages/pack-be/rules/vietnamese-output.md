# Vietnamese Output Rule

- Mọi câu trả lời, heading, checklist, report và artifact `.md` viết bằng tiếng Việt có dấu đầy đủ.
- Không viết tiếng Việt không dấu như `Ke hoach trien khai`, `Khong co blocker`. Lỡ sinh không dấu thì sửa ngay trong cùng lượt.
- Giữ nguyên code identifier, command, path, route, package, API field, DTO, enum, error code, tên bảng/cột DB, tên migration, branch name và nội dung nguyên văn từ source/SRS.
